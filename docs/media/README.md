# Performance-preview footage

IvaYar recorded this gameplay on a physical New Nintendo 3DS LL. The video is a
visual demonstration of this experimental fan port, not a controlled benchmark.
Audio and container metadata were removed from the supplied recording; video
packets were copied without re-encoding. The still is taken from that recording.
The original game imagery belongs to its respective rights holders. This footage
is not a distributable game asset package and is not covered by a blanket code license.
