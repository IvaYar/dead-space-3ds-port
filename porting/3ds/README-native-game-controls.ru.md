Для будущего одного согласованного прогона:

1. Установить именно0.1.6. Прежний полный `SD:/3ds/deadspace/` оставить, ресурсы заново не копировать. Старые приложения и логи сохраняются.
2. Открыть **DS Original Menu0.1.6**, коротко нажать и отпустить A для запуска. Дождаться EA, наушников и полностью появившегося Select Difficulty. Переход автоматический. Загрузка всё ещё может занимать минуты: ускорение подтверждено только в Azahar, аппаратное время ещё неизвестно.
3. Коротко нажать DOWN: ожидается Easy. Дождаться изменения, сделать фото. Затем UP: Normal; затем DOWN: Easy. Между нажатиями дождаться реакции. Уже выбранная строка повторно не нажимается адаптером.
4. B можно один раз коротко проверить, но видимого возврата не ожидать: **первый оригинальный экран игнорирует BACK**. B перед A не нужен. Это не команда закрытия приложения.
5. Один раз коротко нажать A на выбранной сложности. Ожидается автоматическое штатное закрытие. START — отдельный альтернативный запрос безопасного выхода; он может ждать возврата из текущей оригинальной операции.
6. После HOME консоль можно нормально выключить. Во время cleanup питание не выключать. Если возникнет STOPPED/ошибка, сохранить фото и время ожидания; не повторять запуск ради догадок.

Сохранить всю `SD:/3ds/ds-native-game-v0.1.6/`, фото Normal/Easy/последних сообщений, примерные времена до меню и до HOME, последовательность кнопок.
