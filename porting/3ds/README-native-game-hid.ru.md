# Один аппаратный тест DS HID Menu 0.1.7

**Испытание выполнено пользователем и принято:** raw D-pad и A/B прошли, Normal/Easy переключаются, оригинальное A подтверждено; последовал предусмотренный safe exit примерно за 3 с. [Аппаратный отчёт](../analysis/native-game-hid-v0.1.7-hardware/report.ru.md). Повтор 0.1.7 не требуется, новых аппаратных запусков не запрашиваем. Ниже сохранён сценарий выполненного испытания: сначала проверка физических кнопок, затем оригинального меню в том же запуске.

Файл: [native-game.cia](build-native-game-v0.1.7-release/native-game.cia), название **DS HID Menu 0.1.7**, TitleID `000400000FDE7A00`, 360384 bytes. SHA256 `e475440fd0cda08abb561d25ffd3c5de82a4030fc3fe59cdb6b8344e90367906`. Не путать с установленной 0.1.6. Ресурсы остаются прежними; удалять старые результаты не нужно.

## Сразу после запуска: проверка кнопок

1. Дождись `RAW HID CHECK — engine NOT loaded` на нижнем экране. Здесь игра ещё не загружается. **Нажатие A теперь не запускает игру.**
2. По очереди нажми **верхнюю, нижнюю, левую, правую кнопку крестовины**, затем **A**, затем **B**. Каждую удерживай примерно полсекунды и отпускай перед следующей. На экране должны появиться `U:Y D:Y L:Y R:Y A:Y B:Y`, затем `RAW PASS`.
3. Для DOWN отдельно посмотри во время удержания: raw содержит `00000080`; `SDKheld` тоже должен содержать бит `80` (при других зажатых кнопках число может быть суммой). Сделай фото **обоих экранов во время удержания DOWN**, затем фото нижнего экрана после всех шести `Y`. `SDKdown` кратковременный: отсутствие `80` на фотографии само по себе не доказывает ошибку.
4. По желанию один раз отклони Circle Pad вниз и вверх, каждый раз возвращая в центр. Его координаты и большие raw-маски отображаются отдельно; он не заменяет проверку физической крестовины.
5. Если для нижней кнопки `D:Y` не появился, **не жди меню и не нажимай X для загрузки**. Сфотографируй экран, нажми **START**, дождись HOME и передай результаты. Отметь, менялись ли raw и SDKheld при удержании DOWN. Это уже полезный завершённый диагностический тест.
6. Если все шесть `Y` есть, отпусти кнопки. Для проверки только raw можно также закончить через **START**. Для полного согласованного теста нажми **X один раз**: теперь начнётся загрузка оригинального движка. Засеки время именно от **X** до готового меню.

## Когда появилось оригинальное меню

Загрузка пока остаётся долгой: предыдущий аппаратный результат — 9 минут 14 секунд. Не нужно нажимать B перед A или пытаться пропустить наушники. Дождись одновременно экрана `Select Difficulty` сверху и **`ORIGINAL MENU READY`** снизу. Если держал кнопку во время загрузки, сначала отпусти её: старое нажатие намеренно не переносится в готовое меню.

1. Нажми **↓**, удержи около полсекунды, отпусти. Должна выделиться **Easy**. Подожди до 5 секунд и сфотографируй **оба экрана**. Если Easy не выделилась, не жди ещё четыре минуты: один раз удержи ↓ около двух секунд, отпусти и запиши результат. При повторной неудаче сфотографируй экраны и заверши через **START**; A в этом случае не требуется.
2. Если Easy выделилась, нажми и отпусти **↑** — ожидается **Normal**. Запиши, сколько примерно заняла реакция.
3. Нажми и отпусти **↓** ещё раз — ожидается **Easy**. Сделай фото обоих экранов с Easy.
4. Нажми и отпусти **B** один раз. Запиши результат. У исходного первого экрана сложности возврат B игнорируется, поэтому сохранение этого же экрана ожидаемо; это не кнопка выхода.
5. Нажми и отпусти **A один раз**. Это настоящее подтверждение Easy исходным движком. **В этой CIA после подтверждения предусмотрен автоматический safe exit** после двух игровых callback. Начало полноценной игры пока не ожидается. Засеки время от A до HOME; если успеешь, короткое видео перехода полезно, но не обязательно.

Не нажимай START/HOME одновременно с A: для этого сценария важна причина автоматического выхода. Если завершаешь через START, отдельно запиши время START → HOME. На готовом меню ожидается быстрый выход; во время долгого callback он может ждать возврата исходной операции. Если через минуту выхода нет, сфотографируй оба экрана и запиши длительность ожидания — не выдавай принудительное выключение за safe exit. Выключать консоль для извлечения SD следует после возврата в HOME.

Повторный запуск и отдельный HOME → X для этого одного теста не требуются. Если произошёл самостоятельный выход или системная ошибка, зафиксируй последний экран и время, не переигрывай прогон ради «успешного» результата.

## Что передать после завершения

- **Всю папку** `SD:/3ds/ds-native-game-v0.1.7/` архивом с сохранением `run-0001` и других фактически созданных run. Не только `result.json`: нужны `native-game.log`, `hid-preflight.json`, `hid-capture.json`, а при загрузке движка также validation, profiles и остальные файлы. При raw-only запуске отсутствие игровых validation/captures нормально.
- Фото с удержанием физического DOWN и фото всех шести `Y`; если загружал игру — фото Normal/Easy с обоими экранами. При ошибке — фото последнего состояния.
- Короткую запись по шаблону ниже. Непроверенные пункты так и отметь; ресурсы APK/.so/assets присылать повторно не нужно.

```text

Raw: U/D/L/R/A/B = ...; D:Y появился / нет

Circle Pad (если проверял): ...
X → ORIGINAL MENU READY: ... мин ... с / не запускал

Повторное удержание ↓ 2 с (если потребовалось): ...
```
