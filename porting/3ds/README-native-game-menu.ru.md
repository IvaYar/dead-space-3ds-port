# DS Original Menu 0.1.5: один экспериментальный аппаратный прогон

**Аппаратный прогон уже получен. Повтор этой CIA не нужен:** оригинальный Select Difficulty подтверждён, DOWN/A блокируются ошибкой допуска ввода по Azahar CRC, выход по лимиту12000штатный. Stable menu24,02FPS с диагностикой; тяжёлое окно перехода7мин53с. [Разбор полученного hardware run](../analysis/native-game-menu-v0.1.5-hardware/report.ru.md). Следующая проверка требует исправления ввода и отдельного разрешения. Ниже сохранён исторический протокол выполненного прогона.

Это ограниченный native/Prod124 pilot оригинального **Select Difficulty**. Верхний экран рисует оригинальный движок с DS34. D-pad передаёт оригинальные pointer DOWN/UP, A нажимает оригинальную галочку. После подтверждения выполняются ещё два оригинальных callbacks и штатный shutdown. **Игровой процесс в этой CIA не включён. FRAME FAIL сохраняется.**

Пакет: `build-native-game-v0.1.5-r14/native-game.cia`, TitleID `000400000FDE7800`, название `DS Original Menu 0.1.5`. Точные размер/SHA и программные проверки находятся в [release-gate.json](../analysis/native-game-menu-v0.1.5/release-gate.json). Новая CIA агентом на консоли не запускалась; аппаратный запуск требует отдельного разрешения.

Используется прежний полный `SD:/3ds/deadspace/` с проверенным английским донором, assets/apk-assets и subset font. Ресурсы повторно копировать не требуется. Новые writable данные создаются в `test-output/native-game-menu-v015`, журналы — **SD:/3ds/ds-native-game-v0.1.5/run-NNNN/**. Старые установки и журналы имеют другие TitleID/namespace и сохраняются.

Для одного согласованного прогона:

1. Установить указанную CIA, открыть приложение, коротко нажать A для запуска оригинального кода.
2. Дождаться EA, экрана наушников и полностью появившегося Select Difficulty. Первая подготовка меню включает длительный оригинальный callback; точное аппаратное время пока неизвестно.
3. Нажать и отпустить DOWN: должен выделиться Easy. Затем UP: Normal. Затем DOWN: Easy. Между нажатиями дождаться изменения выделения. Удержание не повторяет нажатие.
4. B доставляет Android BACK DOWN/UP. Видимое действие «Назад» на этом первом экране не подтверждено.
5. Нажать A: оригинальный движок получает подтверждение сложности, pilot завершает ограниченное продолжение и закрывается. Для другого выбранного сценария выхода можно использовать START либо HOME→X вместо последнего A.

Навигация разрешается только после наблюдения известного стабильного оригинального меню. Это нужно потому, что повторное нажатие уже выбранной строки может подтвердить сложность. Если аппаратный readback отличается от наблюдавшихся Azahar UI fingerprints, кнопки выбора ждут распознанного кадра; START остаётся доступен. Физический стилус в этом кнопочном pilot не подключён. Числа UI fingerprints используются только для допуска ввода; старый CRC oracle `ea733050` и статус FAIL не меняются.

После прогона нужны вся папка **SD:/3ds/ds-native-game-v0.1.5/**, фото Normal/Easy и последних сообщений, примерные времена запуска/появления меню/закрытия, список нажатий и результат возврата HOME. Если что-то не сработало, описать видимый экран и необходимость POWER. Повторный запуск ради догадок не требуется.

Аппаратные FPS ещё не измерены. В этой сборке `PERFJSON` записывает реальные SDK ticks для callbacks, present, GPU queue/VBlank waits и диагностики, а также последние Citro3D CPU/GPU timings. Подтверждённые аппаратные shutdown/HOME→X относятся к 0.1.4; 0.1.5 проверяется отдельно.

Полный переход к сцене оставлен emulator-only исследованием. Найдены NULL-read в области оригинального EAAudioCore и неподдержанный DS34 fog. [Результат этапа и границы](../analysis/native-game-menu-v0.1.5/report.ru.md).
