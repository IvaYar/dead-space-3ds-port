HOME открывается после безопасного завершения пользователей ресурсов. Если после STOPPED loader всё-таки закончил работу, очистка продолжается **сама, повторный START не нужен**. Если он не возвращается, остаются честный FAIL и удержанные ресурсы.

Это finish-in-flight close, не прерывание чтения в произвольной точке. Старое hardware отличие изображения остаётся FAIL, критерий CRC не ослаблен.

## Один будущий согласованный аппаратный тест

Сначала требуется отдельное согласование. Максимум два запуска одной CIA; при новом отказе не повторять ради данных.

1. Запустить именно **DS Game Progress0.1.4**, нажать **A один раз**. Если получен FRAME FAIL, **не нажимать START**: дождаться автоматического выхода. Записать время от A до FRAME FAIL и до HOME. Если получен FRAME + SEQUENCE SAVED, один START служит исходным запросом выхода; повторные нажатия не нужны.
2. Только после нормального выхода первого запуска: снова A, после заставок нажать **HOME один раз**. После окончания cleanup и появления HOME Menu закрыть приложение **X** с подтверждением. Записать задержку HOME и длительность закрытия после X.

Если появился STOPPED, сфотографировать сообщение и записать время; повторный START для продолжения теперь не нужен. Неполная очистка не объявляется успешной и не освобождает живые ресурсы.

## Что прислать

Пришли **всю папку SD:/3ds/ds-native-game-v0.1.4/** со всеми `run-*`, положив её в `porting`. Нужны фотографии обоих экранов с последним сообщением, а при зависании X — экран закрытия. Текстом: кнопки по порядку, время ожидания, был ли автоматический возврат HOME, потребовался ли POWER и коротко нажимал его или удерживал. Видео не обязательно.

## Повтор программного теста

Существующие результаты и сборки не перезаписываются. Новый isolated card использует тот же verified shared store и отдельные writable файлы:

```powershell
$env:PYTHONDONTWRITEBYTECODE = '1'
python porting/tests/smoke_native_game_progress.py --variant slow --cycles 2 --attempt review1
python porting/tests/smoke_native_game_progress.py --variant stall --attempt review1
python porting/tools/audit_native_game_progress.py
```

Последняя команда проверяет сохранённую финальную матрицу, защитные SHA и CIA payload. Повтор `--cia` запрещён при существующем кандидате. Не удалять его ради обхода проверки.
