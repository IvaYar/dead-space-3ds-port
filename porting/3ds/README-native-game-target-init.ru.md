# DS Game Init0.1.1 — начальная очистка target, эксперимент Prod124

**Аппаратный run-0001 получен: очистка фона работает, полный frame gate FAIL после600callbacks.** Приложение показало STOPPED и намеренно осталось в fail-stop без HID/APT; START/HOME не обрабатывались, shutdown не запускался. Не повторять эту сборку. [Разбор и сравнение raw](../analysis/native-game-target-init-v0.1.1/hardware-report.ru.md), [числа/SHA](../analysis/hardware/native-game-target-init-v0.1.1-user-result.json).

Все33733ранее неотрисованных пикселя теперь чёрные. Но последняя картинка отличается от baseline в9231pixels; причина непрохождения раннего checkpoint ещё исследуется. Фрагменты под Айзеком есть и в сохранённом software baseline. Этот результат не является полным аппаратным game/safe_exit PASS. Ниже сохранены описание сборки и первоначальная процедура уже выполненного пользователем теста; они не разрешают повторный запуск.

Вариант добавляет только однократное заполнение цветового RGBA8 target чёрным до первой оригинальной отрисовки. Шум в незакрашенных областях больше не должен мешать точному CRC всего экрана. Depth, UV shader, GPU backend, ресурсы, RX/cache,20+100MiB/arena92MiB и завершение шести потоков сохранены. Изображение создаёт оригинальная игра; эталонная картинка в CIA не включена. [Обоснование и проверки](../analysis/native-game-target-init-v0.1.1/report.ru.md).

## Первоначальный порядок испытания (выполнено; не повторять)

1. Проверить SHA, установить CIA с названием **DS Game Init0.1.1**. Настройки Luma и прошивку не менять. На нижнем экране должен появиться READY.
2. Нажать **A один раз** и дождаться именно **FRAME SAVED** на нижнем экране. Во время оригинальных callbacks показан экран загрузки; EA и Айзек сами по себе ещё не означают, что контрольный кадр сохранён. START пока не опрашивается на этой стадии. Шумовых областей вне рисунка не ожидается.
3. Только после FRAME SAVED нажать **START один раз**, дождаться завершения и HOME. Предусмотренное ожидание shutdown до30s; отсутствие возврата не считать PASS и не повторять запуск ради проверки.
4. Передать **всю папку `SD:/3ds/ds-native-game-v0.1.1/`**, включая новый run. Нужны native-game.log/result.json/frame.raw/exit.txt и threads snapshots, если созданы. При ранней остановке передать то, что успело сохраниться; повтор не требуется. Игровую `SD:/3ds/deadspace/` присылать не нужно.

Текущий fail-stop на ошибке сохраняет код/арены/стеки/GPU-ресурсы, пока они могут использоваться; автоматического уничтожения потоков нет. Он не обеспечивает START при ошибке до сохранения кадра. Устранение этого ограничения потребует отдельного изменения, чтобы не смешивать факторы с проверкой начального color target. Аппаратный PASS потребует и оригинального кадра, и подтверждённого безопасного выхода.
